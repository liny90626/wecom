# WeCom Changelog Index

本目录记录 OpenClaw WeCom 插件的版本变更。默认先看本 fork 最近 5 个维护版本；原仓库历史版本保留在后续列表中，便于回溯。

## 本 fork 最近 5 个维护版本

- [`v2.5.110-148`](./v2.5.110-148.md)（发布标签 `released/2.5.110-148`）：失败的长任务不再只剩一行英文——走主动推送的错误 final 带上「本次任务未完成（已运行 X）」框架与耗时，并新增 `error-final` 诊断日志以便对齐 OpenClaw 网关日志里被隐去的原始错误；长任务进行中的提示改为请用户耐心等待、尽量不要打断。
- [`v2.5.110-147`](./v2.5.110-147.md)（发布标签 `released/2.5.110-147`）：修复现网反馈的三类问题：一次丢失的企微回执不再永久熄灭进度通道（思考块与过程信息恢复）、错误 final 不再抹掉用户正在看的推理过程、被接管回合的核心失败文案不再以新消息推给用户；并把会话接管改为与 OpenClaw 接受中止同 tick 发布，关闭「已杀掉的 run 仍在线」的窗口。新增忠实建模企微 SDK 投递层的回归套件。
- [`v2.5.110-146`](./v2.5.110-146.md)（发布标签 `released/2.5.110-146`）：以 v118 的低等待路径为参照，恢复入站即时占位、把被接管的 pending 消息并入后继消息、让“已并入/未执行”提示与 OpenClaw 实际结果一致，并在 7.1 拒绝中止时有界等待旧任务释放；同时保留媒体+文字合并去重、pending/active 接管分层与 WS runtime owner 生命周期。开发依赖升级至生产同版本 `2026.7.1`。
- [`v2.5.110-145`](./v2.5.110-145.md)（发布标签 `released/2.5.110-145`）：补齐 external-final 后旧 retry 清理、keepalive 多账号/direct-group 隔离、热重载注册表属主校验，以及 source registry 账号边界和活跃快照淘汰顺序。
- [`v2.5.110-144`](./v2.5.110-144.md)（历史版本，原发布标签已删除；修复由 v145 继承）：外部 source reply 已确认投递后，旧 Bot WS 流直接静默结算，不再误启动 final retry 或推送“本次回复投递中断”；没有新增状态或 timer。

> B1 Markdown 表格、B2 长文本分段/去重、B3 长任务与新消息合并等较早 fork 修复，已统一归档在 [`v2.5.110-112`](./v2.5.110-112.md)；reasoning 思考块系列修复见 [`v2.5.110-113`](./v2.5.110-113.md)。
