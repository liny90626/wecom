# v2.7.260-20（2026-08-28，LinKy fork 候选）

状态：实现、自测、打包与 tag 已完成；待推送维护远端 `fork`。全量测试保留一项当前机器负载导致的既有 `gateway-sim` 超时，详见验证段。

## 根因

`2.7.260-19` 已修正 MCP 到 CLI 的跨品类服务路由，但继续走查发现两个独立的边界问题：

1. 多账号配置使用自定义账号 ID 时，OpenClaw 传入的字面量 `default` 会被旧账号解析器当作默认别名，回退到第一个账号；CLI 工具因此可能拿错企业凭据。
2. CLI 返回的错误 stderr 或 endpoint 诊断属于外部进程输出，超时、exit 2 和普通失败分支此前有路径直接返回；若输出含 secret 或带凭证 URL，会泄露到模型上下文或日志。

## 修复

- 多账号且没有真实 `default` 账号时，拒绝 `default` 合成别名；仍允许显式真实账号 ID。
- 对 CLI 错误 stderr 做 secret 脱敏，并把 endpoint 诊断裁剪到 origin + path；成功路径和既有 MCP 路由不变。
- 增加多账号别名、跨渠道错误组合和泄露式 CLI 输出回归。
