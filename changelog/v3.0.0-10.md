# 3.0.0-10（2026-09-12，LinKy fork）

## 修复

Bot WS 回复在 block 阶段暂存附件，原先只有 final 会上传。当 OpenClaw 返回 deferred、正文已显示时，`closeDeferred()` 直接关流，暂存文件和图片没有进入上传流程。复现时两个附件的上传调用次数为 0。

- `closeDeferred()` 在关流前处理暂存媒体，逐个记录 `phase=deferred-close` 的发送结果。上传返回失败时尝试主动提示并返回 false；提示投递失败写入日志。没有增加自动重试。
- Bot webhook 使用 Agent 私信回退发送文件的循环，将非图片和异常分支中的 `return` 改为 `continue`，继续处理后续媒体。
- 保留正常 final、ACK、正文分片和消息接管路径；无需新增配置或依赖。
