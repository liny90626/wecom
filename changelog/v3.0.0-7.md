# 3.0.0-7（2026-09-06，LinKy fork）

本版修复 Bot WS 合并/延迟回合的空白气泡问题，面向生产 OpenClaw `2026.7.1-2`。

## 修复

当用户连续发送两条消息、第二条被 OpenClaw 接管到仍在运行的回合时，核心可能返回 `noVisibleReplyFallbackEligible`，插件需要关闭原 Bot WS 流。如果该回合尚未产生可见正文，旧逻辑会发送空的终止帧，企业微信客户端因此显示一个空白气泡。

现在关闭流时：

- 已有正文或过程预览时，继续用已显示内容收尾；
- 没有可复用内容时，复用已发送的思考占位文案；
- 不再向企业微信发送空终止帧。
