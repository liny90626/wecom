# 3.0.0-8（2026-09-09，LinKy fork）

长任务过程消息包含 Markdown 表格时，OpenClaw 的部分 commentary 路径会把换行压成空格，企微因此收到单行竖线文本；插件还会误删日期区间的单个 `~`。本版修复这两处问题，并修复步骤编号破坏块级 Markdown、下一步骤被表格吸收的问题。

## 修改范围

- 仅在 Bot WS 过程显示层恢复结构明确、列数一致的压平表格，保留单元格内容，识别行内代码与转义竖线。半行、歧义输入和已有多行 Markdown 不做推测性恢复。
- 表格、标题、引用和列表等块级步骤保留前后边界，普通单行步骤排版不变。
- Markdown 适配器保留单个 `~`，继续降级双波浪号删除线。
- 不改变原始步骤比对、ACK、送达记录、接管逻辑、网络请求或发送节奏；不增加依赖或生产配置。
