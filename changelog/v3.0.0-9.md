# 3.0.0-9（2026-09-11，LinKy fork）

## 修复

OpenClaw 的 reasoning 回调会发送同一思考段的累计快照。插件原有通用合并逻辑无法识别短的末行快照，导致 `No`、`No new`、`Finance`、`Finance still` 等内容逐条出现在思考块中。

新增 reasoning 专用合并：完整累计快照直接更新；当前最后一行的延续快照只替换该行；无法确认是同一快照时沿用原有逻辑追加。正文合并逻辑保持不变。

- Bot WS reply、reply orchestrator、long-task progress：321 个高风险测试通过。
